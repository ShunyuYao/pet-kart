# 桌宠赛车 v0.5.2 · Pet Kart

修复局域网联机时，接收方开车看见其他车辆停顿、随后跳跃追上的问题。产品内入口使用更新后的 HTML；已有对局和聊天附件保存的是旧文件，结束旧局后从游戏入口重新发送并一起玩。

其他车辆按房主比赛时间插值，延迟 150 ms，短暂缺包最多外推 100 ms。切换比赛、赛道、阶段、座位、暂停恢复和退出会重置旧轨迹；瞬移直接切换。接收方自己的操作预测与房主碰撞、计时、排名规则保持原实现。协议仍是 pet-kart v2，最多四人，双方必须使用同一份新 HTML。

新增真实双宿主回归：双方实际按键开车，采集接收方实际 Three 场景根坐标，覆盖普通收包和 180 ms 成批收包，分别验证 2D 与 3D 车手。纯规则门槛新增时钟、缺包、外推上限、瞬移、阶段清空和状态隔离断言；test:integration 包含双端平滑度、三人完整对局和产品缓存入口。

## English

Fixes remote cars freezing and then jumping ahead while the receiving player drives in a LAN race. Other cars use host simulation time, a 150 ms presentation buffer and at most 100 ms of extrapolation. Race/track/phase/seat changes, suspension and disconnects reset stale motion. Local input prediction and host collision/results remain unchanged. Protocol stays pet-kart v2, up to four players; both sides need the same updated HTML.

Received attachments and open matches retain their original bytes. End the old match and send the new game from the product's game entry. Real hidden-host regressions use actual CDP keys and rendered scene positions with normal and batched SDK traffic, for both 2D and 3D drivers. The integration gate also covers a complete three-player race and cached catalog entry after restart. These tests do not certify physical two-machine networking, native focus or public internet play.
