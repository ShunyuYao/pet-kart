# 赛道机关与空中驾驶（2026-10-15）

用户要求让五张地图拥有可玩的高低差、跳跃滑翔和与环境相关的干扰互动。借鉴街机赛车的节奏，不使用其他游戏的美术资产。

现有高度道路、3D 原语和真实 CDP 测试齐备。用户明确确认无新设计，沿用现有风格原创场景。Context7 本次不可用，图形 API 核对官方 three.js r164 文档。

## 行为与可追溯验收
1. 向前且速度足够驶过跳台末端才起跳；倒车、低速及绕行不会起跳。坡面有真实高度。空中不能蓄漂移，不能触发地面加速带/香蕉或撞到下方车。
2. 滑翔台自动展开伞，左右操纵航向，刹车加快下降；落地收伞，稳定落地获得短加速。一次跳台通行只触发一次，下一圈可再次触发。结束/重开清除状态。
3. 火山喷口先预警再喷发，再进入冷却；只有危险阶段实际相交才受击，并有短暂受击保护。热气流给滑翔车升力。
4. 雪地冰面降低抓地力，离开恢复；冰块和滚雪球可绕开/从上方越过。其余地图滚动奶酪、摆动毛线球、夜城机械路障及风道与主题相符。障碍不封死整幅路面。
5. 机关由比赛时间确定，同一快照两端位置/周期相同。高度、垂直速度、展开状态进快照，客端预测和远端插值保留；不可改成仅主机有物理效果。
6. 所有电脑对手遵守同样物理；五赛道能完整结束。保留原漂移、道具、换图、重赛与联机轨迹门槛。

改动 → 消费路径 → 所选测试：terrain/track/sim → 单人及联机规则 → test:rules（扩充 tracks 原断言）；scene/main → 真实驾驶/渲染 → test:terrain:e2e（隐藏 Electron，真实键盘全五图）；快照/预测 → 联机 → test:host 和 test:remote-motion；最终 HTML → test:artifact。不执行无关宿主 UI/AI 门槛。

## 实现地图
- `game/terrain.cjs`：五图 30 处跳台、风道、冰面和障碍；比赛时间决定位置/预警/伤害窗口；坡面高度、飞行重力、上升气流、侧风、落地奖励与受击保护。
- `game/sim.cjs`：权威物理与客端共用飞行/侧风；空中隔离地面加速带；完整快照。
- `game/ai.cjs`：沿途预测移动障碍的将来位置，选择可通行车道，仍发送普通驾驶意图。
- `src/terrain-scene.js` / `scene.js`：原创程序几何、指示牌、滑翔伞和绳索、动态喷口与冰面；渲染复用同一机关位置。空中摄像机拉远。
- `src/main.js`：纵向预测校正、起飞/落地/撞机关提示；沿用原操作键位。
- 仅游戏互动协议升 v3，SDK 声明仍 v2。包版本 0.6.0。旧游戏与新游戏不混局；无宿主 SDK/类型/脚手架/市场接口变化，无公开发布动作。
